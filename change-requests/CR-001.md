# CR-001: 缺少專案封存端點

- **提出者**: backend
- **狀態**: proposed
- **阻擋任務**: TASK-004

## 問題
`tasks.yaml` 的 TASK-004 要求封存功能,但 `openapi.yaml` 沒有任何可以修改
`Project.status` 的端點。Project schema 有 `archived` 這個 enum 值,卻沒有
路徑能把專案切換過去。

## 影響
不改 contract 的話,我只有兩條路:
1. 自己在 openapi.yaml 加一個端點 —— 違反邊界規則。
2. 硬做一個沒寫進 contract 的隱藏端點 —— frontend 拿不到型別,QA 測不到。

兩條都不該走,所以停下這個任務、開這份 CR。

## 建議變更
新增 `PATCH /projects/{projectId}`,request body:

```yaml
UpdateProjectRequest:
  type: object
  properties:
    status:
      $ref: '#/components/schemas/ProjectStatus'
```

## 波及範圍
- `generated/api.ts` 新增 operation,屬純新增,不會破壞既有程式碼。
- frontend 需新增一顆封存按鈕(TASK-005,待建)。
- QA 需為 AC-007 補測試。
